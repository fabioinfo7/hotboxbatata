HOTBOX — CENTRAL PROFISSIONAL DE CHAT E PEDIDOS

ORDEM SEGURA DE APLICAÇÃO
1. Faça backup do projeto/banco antes do deploy.
2. Execute no Supabase SQL Editor:
   supabase/migrations/20260830_chat_central_operador.sql
3. Substitua somente estes arquivos pelos arquivos desta pasta:
   src/routes/_authenticated/loja.chat.tsx
   src/routes/_authenticated/loja.pedido.$id.tsx
   src/lib/generate-order-from-chat.functions.ts
   src/styles.css
4. Faça o deploy normalmente.

A migration usa apenas ADD COLUMN IF NOT EXISTS e CREATE INDEX IF NOT EXISTS.
Ela não apaga, move ou renomeia dados existentes.

A lógica de conversa automática do WhatsApp não foi alterada.
