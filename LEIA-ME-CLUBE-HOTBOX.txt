HOTBOX DELIVERY — CLUBE HOTBOX / PROGRAMA DE FIDELIDADE

O QUE FOI IMPLEMENTADO
- Cadastro/login OPCIONAL no cardápio.
- Login com Google via Supabase Auth.
- Login/cadastro por e-mail e senha também disponível.
- Cliente sem conta continua comprando normalmente.
- Apenas pedidos feitos LOGADO + PAGOS + ENTREGUES pelo cardápio digital contam para fidelidade.
- A cada 10 pedidos válidos, o sistema cria automaticamente um cupom individual HB-FIEL-XXXXXXXX.
- O cupom vale 1 unidade de uma batata marcada como participante.
- O cliente paga a taxa de entrega e quaisquer outros itens do carrinho.
- O cupom só pertence à conta que o ganhou.
- O cupom é reservado durante o checkout para impedir uso duplo.
- Se o checkout expirar/falhar/cancelar, o cupom volta a ficar disponível.
- Depois do pagamento confirmado, a recompensa vira REDEEMED e o cupom fica inativo.
- Pedido que usa recompensa NÃO gera ponto novo de fidelidade.
- No card do pedido aparece uma faixa verde grande: CLIENTE FIEL — TEM DIREITO A UMA BATATA GRÁTIS.
- A página /loja/fidelidade permite controlar programa, número de pedidos e quais produtos participam.
- Cupons promocionais normais (inclusive códigos divulgados no Instagram) continuam funcionando como antes.

EXPERIÊNCIA DO CLIENTE
O cardápio mostra o “Forno da Fidelidade HotBox”, com 10 posições visuais. Cada pedido concluído acende mais uma posição. Ao completar a meta, aparece o cupom da batata grátis com botão para usar.

ORDEM DE INSTALAÇÃO
1) Execute no Supabase SQL Editor:
   supabase/migrations/20260903050000_clube_hotbox_fidelidade.sql
2) Copie os arquivos deste pacote respeitando exatamente as pastas.
3) Faça deploy no Railway.
4) Configure Google no Supabase (passos abaixo).
5) Entre em /loja/fidelidade e confira quais produtos estão marcados como “Batatas participantes”.
6) Faça os testes descritos em TESTAR-CLUBE-HOTBOX.txt.

CONFIGURAR LOGIN GOOGLE NO SUPABASE
- Supabase Dashboard > Authentication > Providers > Google.
- Ative Google.
- No Google Cloud Console, crie/configure um OAuth Client Web.
- Use a Callback URL mostrada pelo próprio Supabase na configuração do provider Google.
- No Supabase > Authentication > URL Configuration, deixe o endereço público da HotBox autorizado:
  https://hotbox.up.railway.app
- Site URL recomendado: https://hotbox.up.railway.app

IMPORTANTE
O código não inventa Client ID/Secret do Google. Essas duas credenciais são fornecidas pelo Google Cloud e devem ser cadastradas somente no Supabase.
