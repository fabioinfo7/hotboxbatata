CORREÇÃO DO ERRO 42P16 - store_config_public

O erro ocorria porque CREATE OR REPLACE VIEW não permite mudar o nome/posição das colunas já existentes.
A migration original colocou stripe_pix_enabled antes de digital_menu_cash_enabled.

CORREÇÃO:
A ordem existente foi preservada e stripe_pix_enabled foi adicionada ao FINAL da view.

COMO APLICAR:
1. No Supabase > SQL Editor, abra o arquivo corrigido:
   supabase/migrations/20260901021000_cardapio_checkout_pago_stripe_pix.sql
2. Execute o arquivo inteiro novamente.
3. Como o primeiro comando usa ADD COLUMN IF NOT EXISTS e CREATE TABLE IF NOT EXISTS, é seguro reexecutar após a falha anterior.

Não é necessário apagar a coluna stripe_pix_enabled caso ela tenha sido criada antes do erro.
