ORDEM DE INSTALAÇÃO — HOTBOX DUPLO GATEWAY

1. Faça backup/commit da versão atual do projeto.
2. No Supabase SQL Editor, execute TODO o arquivo:
   supabase/migrations/20260903060000_dual_gateway_mercadopago.sql
3. Só depois do SQL concluir com sucesso, copie os arquivos src/ deste pacote para as mesmas pastas no projeto.
4. Faça deploy no Railway.
5. Crie/abra a aplicação da HotBox no Mercado Pago Developers.
6. Ative Credenciais de Produção usando o site https://hotbox.up.railway.app
7. Copie Public Key e Access Token de PRODUÇÃO.
8. HotBox > Configurações > Pagamentos:
   - Ative Mercado Pago.
   - Cole Public Key.
   - Cole Access Token.
   - Deixe máximo de parcelas em 1x inicialmente.
   - Mantenha InfinitePay habilitada/configurada como contingência.
   - Selecione Mercado Pago em Provedor ativo.
   - Salve.
9. Faça primeiro um Pix de valor baixo e depois um cartão de valor baixo.
10. Execute TESTES-OBRIGATORIOS.txt, inclusive a troca manual para InfinitePay.
